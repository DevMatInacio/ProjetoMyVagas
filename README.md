💼 MyVagas - Sistema de Gerenciamento de Vagas

Sistema completo de gerenciamento de vagas de emprego desenvolvido em Spring Boot, inspirado em plataformas como Indeed e LinkedIn.

🚀 Funcionalidades

👥 Sistema de Usuários
- **Cadastro dual**: Candidatos e Empresas
- **Autenticação segura** com sessões
- **Dashboard personalizado** para cada tipo de usuário

🎯 Para Candidatos
- Perfil profissional completo (currículo, experiência, contato)
- Busca e visualização de vagas disponíveis
- Sistema de candidaturas
- Acompanhamento de status das candidaturas

🏢 Para Empresas
- Cadastro e gerenciamento de vagas
- Visualização de candidaturas recebidas
- Controle de status (Pendente/Selecionado/Rejeitado)
- Dashboard com métricas e estatísticas

📊 Sistema de Candidaturas
- Controle completo do processo seletivo
- Status em tempo real
- Histórico de candidaturas
