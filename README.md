Projeto Sistema de Vagas (Estilo Indeed)

Este projeto foi desenvolvido como atividade acadêmica com o objetivo de simular um sistema de vagas de emprego, inspirado em plataformas como o Indeed.  

O sistema permite cadastrar usuários, empresas, candidatos, vagas e gerenciar candidaturas.



📌 Funcionalidades

- Cadastro de **Usuários** (base para empresas e candidatos).  
- Cadastro de **Candidatos** (com informações pessoais e perfil).  
- Cadastro de **Empresas** (com dados da organização).  
- Registro de **Vagas de Emprego** vinculadas às empresas.  
- Realização de **Candidaturas** de candidatos em vagas.  
- Programa principal para executar e testar o sistema.



🛠️ Tecnologias utilizadas

- **Java** (versão X, substitua pela que usou — ex: Java 17)  
- **IDE**: Eclipse (ou a que você utilizou)  



📂 Estrutura do Projeto

src/
 Programa.java        # Classe principal (main)
 Usuario.java         # Classe base para usuários
 Candidato.java       # Representa um candidato
 Empresa.java         # Representa uma empresa
 Vaga.java            # Representa uma vaga de emprego
 Candidatura.java     # Relaciona candidato e vaga


▶️ Como executar

1. Clone este repositório:
   bash
   git clone https://github.com/DevMatInacio/ProjetoVagas
   

2. Compile os arquivos:
   bash
   javac src/*.java
   

3. Execute o programa principal:
   bash
   java Programa
